
# Python Fundamentals for Data Science & Machine Learning

This repository contains my practice codes and problem-solving exercises completed during the **Oosthad Data Science & Machine Learning Live Course**.

## 📚 Topics Covered

### 1. Variables, Data Types & Logic
- **Variables & Data Types:** Understanding dynamic typing and basic data structures.
- **Conditional Logic:** Implementing `if`, `elif`, and `else` statements.
- **Operators:** Working with logical, comparison, relational, and conditional operators.

### 2. Loops, Strings & Smart Operations
- **Loops:** Control flow using `for` loops and `while` loops.
- **Loop Control:** Efficient handling using `break` and `continue` statements.
- **String Manipulation:** Basic to advanced string operations and formatting.
- **Mathematical Operations:** Arithmetic operators, operator precedence, and built-in math functions.

---
*Goal: Building a strong foundational knowledge in Python to apply in Data Science algorithms.*
